# Blokzen iOS

The Blokzen web game (`www/index.html`) wrapped as a native iPhone app with Capacitor 7.

- Every push to `main` builds an unsigned `Blokzen.ipa` on a GitHub-hosted Mac (see the **Actions** tab, artifact `Blokzen-ipa`).
- Install it on an iPhone from Windows with Sideloadly using your Apple ID. A free Apple ID install runs for 7 days; re-install to refresh.
- To update the game: replace `www/index.html` and push.
